# ChemAI · 当前架构

浏览器 `app/index.html` → Python 标准库 HTTP 服务 `app/server.py` → 自写 `ChemAIAgent` → 配置的模型 API。

Agent 使用文本工具协议，按角色检查工具权限；知识库为本地 JSONL 关键词检索。四个工具分别为检索、示例学生档案、教师专属示例班级概览、记录信息缺口。

## 已实现边界

- 会话保存在内存，每个会话最多保留最近 8 条消息；请求回填同一会话和角色的近期上下文，总长上限 12,000 字符。服务重启后记录清空。
- 输出护栏返回风险标记，回答仍被返回和显示；没有输出阻断。
- 角色来自请求参数，没有账号登录与真实班级授权。
- 模型调用配置来自环境变量或本地 `.env`。
- 额度保护用于演示，不代表生产级资源治理。

LangGraph、FastAPI、数据库、向量检索、OCR、配平审核及完整教学闭环均不是当前原型能力。历史架构设想见[附录](../附录/README.md)。
