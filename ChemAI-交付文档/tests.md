# ChemAI · 评测覆盖与缺口

## 已有证据

15 条自建教师样例；两版提示各三轮，共 90 次输出。另有三端行为探针记录。见[实验汇总](../eval/实验结果汇总.md)。历史数据仅代表当时参数和样例，不保证当前模型服务仍返回同样结果。

| 检查 | 实际口径 | 未覆盖 |
|---|---|---|
| 输出结构 | 四个小节关键词齐全 | v2 六节结构和内容有效性 |
| 引用 | 是否含引号 | 是否引用学生原文、是否支持结论 |
| 追问 | 缺信息子集是否含追问词 | 独立发现缺信息与追问有效性 |
| 裁判通过 | 模型裁判加硬违规否决 | 教师金标准准确率 |
| 耗时 | 模型调用累计时间 | 完整网页响应耗时 |
| 风险检测 | 输出风险标记 | 输出阻断和安全保证 |

## 验证缺口

需增加教师盲评、独立留出集、移除歧义标签的对照，以及角色工具拒绝、会话归属、有限历史窗口截断和输出阻断的独立测试。不能把检测命中当作功能通过。

本文为覆盖说明，不表示这些待办测试已执行。运行配置检查使用 `--dry-run`，不调用模型，也不会生成质量评测结果。
