# ChemAI 评测工具与复跑说明

评测对象为教师端文本分析。现有数据来自 15 条自建样例，v1/v2 各三轮，共 90 次输出。不是 90 条独立样本，也不是教师标注的教学效果实验。

## 阅读入口

[核对后的实验汇总](实验结果汇总.md) · [样例](cases.jsonl) · [v1 提示](prompts/system_v1.md) · [v2 提示](prompts/system_v2.md) · [原始记录](runs/)

`runs/` 保留历史报告与原始输出。为适合公开阅读，历史报告和提示快照中的非产品准备备注已做编辑性清理；评测指标与原始模型输出未改动。提示快照用于展示任务约束，不保证与历史请求逐字一致。

## 指标边界

- 结构：检查四个小节关键词；v2 提示实际要求六节，不是六节完整验收。
- 引用：检查引号，不核验引用来源或支持关系。
- 追问：对歧义非 none 的样例检查追问关键词，不判断追问是否有效。
- 通过率：模型裁判判定，并可被硬违规规则否决；不是化学准确率。
- 耗时：每条样例模型请求累计耗时，不含裁判与完整网页链路。
- 成本：脚本价格表估算，非账单，价格需自行核对。

输入中提供了参考答案和歧义标签；v1 也叠加角色规则和工具协议。当前无教师人工金标准及独立留出测试集。

历史六轮评测按样例分别调用 Agent，每条样例使用新的会话，因此没有评估后来加入的多轮上下文功能；历史指标不代表多轮对话表现。

## 不调用模型的检查

在仓库根目录运行：

```powershell
python eval/run_eval.py --agent --prompt eval/prompts/system_v2.md --dry-run
```

## 配置并复跑

在当前终端设置 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。评测脚本不自动加载 `app/.env`。模型标识须使用供应商实际支持的值；不据历史请求名推断底层版本。

```powershell
python eval/run_eval.py --agent --prompt eval/prompts/system_v1.md --tag v1-new
python eval/run_eval.py --agent --prompt eval/prompts/system_v2.md --tag v2-new
```

真实运行会调用模型并产生 API 费用。保留调用日期、请求及返回模型标识、样例、提示指纹、原始输出和失败原因。当前代码的元数据主要记录请求模型名，返回模型版本留存仍需补齐。

`run_all.py` 用于串行运行两版；`check_persona.py` 是独立的三端行为探针，不与教师端主实验混算。多轮重复不等于多次 Prompt 迭代。
